## ✅ Demo Slice 4 (น็อคเอาท์) — จัดสายจากตารางคะแนน → สายแข่งสาธารณะ · มอบหมายกรรมการสนาม · ชุดคลิปมาตรฐาน · แก้เกณฑ์

**ก่อนลอง:** ดึงโค้ดใหม่ → `pnpm db:deploy` → `pnpm db:seed` (`SEED_DEMO=1`) → เปิด API ใหม่ · การอัปโหลดคลิปต้องเปิดที่เก็บไฟล์ MinIO ไว้ด้วย (`docs/qa/slice1-e2e.md`) · รหัสผ่าน: ดูในไฟล์ `.env`

*มอบหมายกรรมการสนาม*

3. ตารางแมตช์: เลือก **สนาม** และ **กรรมการ** ทีละแมตช์ · ระบบไม่ยอมให้เลือกกรรมการที่ลงแข่งในแมตช์นั้นเอง หรือแมตช์ที่ล็อกผลแล้ว (ขึ้นว่า "ไม่สามารถมอบหมายได้")
4. ล็อกอินเป็น `umpire1@blulens.local` → `/umpire` → เห็นแมตช์ที่ได้รับมอบหมาย

*จัดสายน็อคเอาท์* (ต่อจาก Slice 3 หลังกด **ยืนยันผลรอบกลุ่ม** แล้ว)

2. ถ้ารอบแรกมีคนทีมเดียวกันหรือมาจากกลุ่มเดียวกันเจอกัน (เลี่ยงไม่ได้) ระบบขึ้นรายการ "พบทีมหรือกลุ่มที่ชนกันในรอบแรก" · จัดใหม่ได้แต่ต้องใส่เหตุผล
3. **เผยแพร่** → ขึ้นว่า "เผยแพร่สายน็อกเอาต์แล้ว" (เผยแพร่แล้วจัดใหม่ไม่ได้) → ระบบสร้างแมตช์รอบแรก (รอบน็อคเอาท์แข่ง 2 ใน 3 เกม เกมละ 21 แต้ม)
4. กรรมการสนามกรอกผล → คณะกรรมการยืนยัน (ขั้นตอนเดียวกับ Slice 3) → ผู้ชนะเลื่อนไปรอบถัดไปเอง
5. หน้าสายแข่งสาธารณะ (ไม่ต้องล็อกอิน): http://localhost:3100/events/<รหัสประเภท>/bracket (มีลิงก์จากหน้าตารางคะแนน) → ชื่อรอบ (เช่น รอบ 8 ทีม / รองชนะเลิศ / รอบชิง), แมตช์ชิงที่ 3 และ **แชมป์** · ก่อนจับสายแสดงเป็น "แชมป์กลุ่ม A" ฯลฯ ไม่เดาชื่อ

*ชุดคลิปมาตรฐาน* (ใช้ตรวจว่ากรรมการให้คะแนนเข้มหรืออ่อนกว่าเกรดอ้างอิง)
1. ล็อกอินเป็น `committee@blulens.local` → หน้าแรกคณะกรรมการ → **ชุดคลิปมาตรฐาน** → **สร้างชุดใหม่** → **สร้างชุด**
2. **เปิดชุด** → อัปโหลดคลิป (mp4/mov ไม่เกิน 500 MB และ 5 นาที) พร้อมเลือกเกรดอ้างอิง · แก้เกรดหรือลบคลิปได้จนกว่าจะมอบหมาย
   - หลังอัปโหลดสำเร็จ เลือกคลิปถัดไปได้ทันที (แก้แล้ว develop `7158586` · ยังไม่ได้ทดสอบซ้ำ ถ้าปุ่มค้างให้รีเฟรชหน้า)
3. **มอบหมายผู้ตรวจ** → เลือก `reviewer1`–`reviewer3` (มอบหมายแล้วแก้คลิปและเกรดอ้างอิงไม่ได้ · เพิ่มผู้ตรวจภายหลังได้)
4. ผู้ตรวจเห็นงานในคิว `/review` เหมือนงานปกติ (ไม่รู้ว่าเป็นคลิปชุดมาตรฐาน) → ให้คะแนน
5. กลับมาที่ชุด → ตาราง **ความลำเอียงเทียบเกรดอ้างอิง**: แต่ละผู้ตรวจ "0 ขั้น (ตรงเกณฑ์)" / "ให้คะแนนสูงกว่าเกณฑ์" / "ต่ำกว่าเกณฑ์" · ให้คะแนนน้อยเกินไปขึ้นว่า "ข้อมูลยังไม่พอ"

*แก้เกณฑ์การประเมิน (rubric)* (ทดสอบผ่าน 10/10 develop `63a010a`)
1. ล็อกอินเป็น `committee@blulens.local` → หน้าแรกคณะกรรมการ → **เกณฑ์การประเมิน** (`/committee/rubrics`) → เห็นทุกเวอร์ชัน: **ใช้งานอยู่** / **ฉบับร่าง** / **เลิกใช้แล้ว**
2. **สร้างร่างจากเกณฑ์ที่ใช้อยู่** (มีร่างได้ทีละ 1 ฉบับ) → **แก้ไข**
3. แก้ได้: **ชื่อเกณฑ์**, **น้ำหนัก** (มากกว่า 0 ไม่เกิน 10 · เห็นสัดส่วน % ทันที), คำอธิบายแต่ละระดับ (มือใหม่ → มืออาชีพ), **+ เพิ่มเกณฑ์** / **ลบเกณฑ์** / เลื่อน **ขึ้น** / **ลง** → **บันทึก** (มีข้อผิดพลาดระบบบอกจำนวนและไม่ให้บันทึก)
4. กลับไปรายการ → **เปิดใช้** → ใส่เหตุผลอย่างน้อย 5 ตัวอักษร → เกณฑ์เดิมถูกเลิกใช้ · เกณฑ์ที่ใช้งานแล้วแก้ไม่ได้ (ต้องสร้างร่างใหม่) · ลบได้เฉพาะร่าง
   - สูตรคำนวณที่เจ้าของอนุมัติแล้วแก้ไม่ได้จากหน้านี้ · คำขอที่ส่งก่อนเปลี่ยนยังใช้เกณฑ์เดิม

## ✅ Demo Slice 3 (แข่งจริง) — จับกลุ่ม → กรรมการสนามกรอกผล → คณะกรรมการยืนยัน → ปิดรอบกลุ่ม → ตารางคะแนน

ทดสอบผ่านเบราว์เซอร์อัตโนมัติ (Dwight + Kelly): วงจรเต็ม จับกลุ่ม → เผยแพร่ → เพิ่มกรรมการสนามจากหน้าเว็บ → รายงานผล → ยืนยัน → ปิดรอบกลุ่ม → หน้าตารางคะแนนสาธารณะ เขียว 3 รอบติด โดยไม่แก้ฐานข้อมูลเอง (develop `f1edab3`, ชุดทดสอบ `9e1d07b`)

| ขั้น | สิ่งที่ทำ | API | หน้าเว็บ |
|---|---|---|---|
| 1 | คณะกรรมการ **จับกลุ่ม** (ดูตัวอย่าง → รับทราบทีมชน + ใส่เหตุผล) → **เผยแพร่** → ระบบสร้างแมตช์ในกลุ่ม | ✅ | ✅ |
| 2 | กรรมการสนามเปิดแมตช์ของตัวเองที่ `/umpire` แล้วกรอกคะแนนทีละเกม | ✅ | ✅ |
| 3 | คณะกรรมการ **ยืนยันผล** หรือ **ส่งกลับให้กรรมการ** (เหตุผลอย่างน้อย 5 ตัวอักษร) | ✅ | ✅ |
| 4 | ตารางคะแนนสด (ยังไม่ยืนยันกลุ่ม = แสดงว่า "ชั่วคราว") | ✅ | ✅ |
| 5 | **ยืนยันผลรอบกลุ่ม** เมื่อยืนยันครบทุกแมตช์ → ล็อกผล + บอกว่าใครเข้ารอบ | ✅ | ✅ |
| 6 | จัดสายน็อคเอาท์จากตารางคะแนน (ดู Slice 4 ด้านบน) | ✅ | ✅ |

**ก่อนลอง:** ดึงโค้ดใหม่ → `pnpm db:deploy` → `pnpm db:seed` (ต้องมี `SEED_DEMO=1` · ข้อมูลเดิมไม่หาย) → เปิด API ใหม่ · รหัสผ่านทุกบัญชี: ดูในไฟล์ `.env`

**ทางลัด:** ประเภทคู่ชาย (MD) ของรายการ "ศึกลูกขนไก่ชิงถ้วยประธานชมรม ครั้งที่ 3" ในข้อมูลตัวอย่างมีกลุ่มที่เผยแพร่แล้ว 1 กลุ่ม 3 แมตช์ (ยืนยันแล้ว 1 · รอยืนยัน 1 · ยังไม่แข่ง 1) และมี `umpire1` อยู่แล้ว → ข้ามไปข้อ 4 ได้เลย

1. สร้างประเภทใหม่ด้วย wizard (`/events/new`) เลือกรูปแบบ **แบ่งกลุ่ม + น็อคเอาท์** → เพิ่มคู่และให้คณะกรรมการอนุมัติอย่างน้อย 3 คู่ (ขั้นตอนเดียวกับ Slice 1)
2. ล็อกอินเป็น `committee@blulens.local` → เปิดประเภทนั้น → **จัดกลุ่ม** → **จับกลุ่ม** → ดูตัวอย่างกลุ่ม (ถ้ามีคนทีมเดียวกันอยู่กลุ่มเดียวกัน ต้องกดรับทราบ) → จับใหม่ได้แต่ต้องใส่เหตุผล → **เผยแพร่** (เผยแพร่แล้วจับใหม่ไม่ได้)
3. ที่ประเภทนั้น กด **มอบหมายกรรมการสนาม** → **เพิ่มกรรมการ** → เลือก `umpire1` → ปล่อยเป็น **ทุกสนาม**
4. ออกจากระบบ → เข้าสู่ระบบเป็น `umpire1@blulens.local` → http://localhost:3100/umpire → แมตช์ที่ **รอกรอกผล** → กด **กรอกผล** → ใช้ปุ่มเพิ่ม/ลดแต้ม เช่น 15–11 และ 15–9 → ส่งผล → **ผลถูกรายงาน**
   - คะแนนผิดกติกา (ยังไม่ครบ 15 แต้ม หรือเสมอ 15–15) ระบบแจ้งเป็นภาษาไทยและส่งไม่ได้ · กรรมการสนามกรอกผลแมตช์ที่ตัวเองลงแข่งไม่ได้
5. ออกจากระบบ → เข้าสู่ระบบเป็น `committee@blulens.local` → `/events` → เปิดรายการ → ที่ประเภทนั้น กด **ผลที่รอยืนยัน** → กด **ยืนยันผล** ทีละแมตช์ (หรือ **ส่งกลับให้กรรมการ** พร้อมเหตุผล) จนคิวว่าง
6. ปุ่ม **ยืนยันผลรอบกลุ่ม** จะกดได้เมื่อยืนยันครบทุกแมตช์ → กด → dialog แสดงรายชื่อคู่ที่เข้ารอบ → ยืนยัน → ผลรอบกลุ่มถูกล็อก (แก้ผลไม่ได้อีก)
7. เปิดหน้าตารางคะแนนสาธารณะ (ไม่ต้องล็อกอิน): http://localhost:3100/events/<รหัสประเภท>/standings (รหัสประเภทอยู่ใน URL ของข้อ 5) → เห็นตารางสุดท้าย ก่อนข้อ 6 หน้านี้จะขึ้นว่าเป็นผล "ชั่วคราว"

## ✅ การแจ้งเตือนในระบบ — กระดิ่งบนแถบเมนู + หน้ารายการแจ้งเตือน

ทดสอบผ่านเบราว์เซอร์อัตโนมัติ (Dwight): เขียว 3 รอบติด (ชุดทดสอบ `6389ed7`, ทั้งชุด 130 รายการผ่าน) · v1 แจ้งในระบบอย่างเดียว ไม่มีอีเมล

**ใช้ร่วมกันทุกบทบาท:** กระดิ่ง **แจ้งเตือน** บนแถบเมนูแสดงจำนวนที่ยังไม่อ่าน (อัปเดตเองทุกประมาณ 1 นาที หรือตอนเปลี่ยนหน้า) → กด → หน้า `/notifications` · รายการที่ยังไม่อ่านขึ้นก่อน · กดรายการเพื่อไปยังหน้าที่เกี่ยวข้อง (นับว่าอ่านแล้ว) · ปุ่ม **อ่านทั้งหมด** · ว่าง = "ยังไม่มีการแจ้งเตือน" · คนที่กดเองไม่ได้รับแจ้งเตือนของตัวเอง

*ทางของกรรมการให้คะแนน*
1. ล็อกอินเป็น `committee@blulens.local` → เปิดคำขอประเมินที่รอมอบหมาย → มอบหมายให้ `reviewer1`
2. ออกจากระบบ → ล็อกอินเป็น `reviewer1@blulens.local` → กระดิ่งมีตัวเลข → "มีงานประเมินใหม่ 1 งาน" → กดแล้วไปที่คิว `/review`
   - ข้อความเหมือนกันทั้งงานจริงและชุดคลิปมาตรฐาน และไม่บอกชื่อผู้ถูกประเมิน (กติกาประเมินแบบปิดชื่อ)

*ทางของสมาชิก*
1. คณะกรรมการ **อนุมัติ** / **ส่งกลับ** / **ปรับผล** คำขอประเมิน (ขั้นตอนเดียวกับ Slice 2)

## ✅ Demo Slice 2 (ประเมินมือ) — กรรมการให้คะแนน + คณะกรรมการตัดสินผล กดได้ครบวงแล้ว
