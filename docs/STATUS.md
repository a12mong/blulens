*ช่วงที่ 1 — กรรมการสนามกรอกผล*

2. กด **กรอกผล** → ใช้ปุ่มเพิ่ม/ลดแต้มกรอกทีละเกม เช่น 15–11 และ 15–9 → ส่งผล → ขึ้นว่า **ผลถูกรายงาน**
   - ถ้าคะแนนผิดกติกา (เช่น ยังไม่ครบ 15 แต้ม หรือเสมอ 15–15) ระบบแจ้งเป็นภาษาไทยและส่งไม่ได้ · กรรมการสนามกรอกผลแมตช์ที่ตัวเองลงแข่งไม่ได้

*ช่วงที่ 2 — คณะกรรมการยืนยันผล*
1. ออกจากระบบ → เข้าสู่ระบบเป็น `committee@blulens.local` (รหัสผ่าน: ดูในไฟล์ `.env`) → ไปที่ `/events` → เปิดรายการ "ศึกลูกขนไก่ชิงถ้วยประธานชมรม ครั้งที่ 3"
2. ที่ประเภทคู่ชาย กดปุ่ม **ผลที่รอยืนยัน** → เห็นผลที่กรรมการสนามรายงานพร้อมคะแนนแต่ละเกม
3. กด **ยืนยันผล** → ยืนยันใน dialog → แถวหายจากคิว และตารางคะแนนนับแมตช์นี้แล้ว
   - หรือกด **ส่งกลับให้กรรมการ** → ใส่เหตุผลอย่างน้อย 5 ตัวอักษร → แมตช์กลับเป็น "ยังไม่แข่ง" ให้กรรมการสนามกรอกใหม่
4. ดูตารางคะแนน: ตอนนี้ยังไม่มีหน้าเว็บ · ดูข้อมูลดิบได้ที่ `http://localhost:3101/api/v1/events/<รหัสประเภท>/standings` (รหัสประเภทอยู่ใน URL ของข้อ 2)

**ที่ยังไม่มี:**

## ✅ Demo Slice 2 (ประเมินมือ) — กรรมการให้คะแนน + คณะกรรมการตัดสินผล กดได้ครบวงแล้ว

ทดสอบผ่านเบราว์เซอร์อัตโนมัติ (Dwight): ฝั่งกรรมการให้คะแนน เขียว 3 รอบติดบน develop `68deb89` · ฝั่งคณะกรรมการ เขียว 3 รอบติดบน develop `239678a` · ส่งกลับ + มอบหมายกรรมการเพิ่ม เขียว 3 รอบติดบน develop `b322b35`

| ขั้น | สิ่งที่ทำ | API | หน้าเว็บ |

| 2 | เปิดงาน ดูคลิป ให้เกรดทุกเกณฑ์ (มีบันทึกร่างในเครื่อง ปิดหน้าแล้วเปิดใหม่ยังอยู่) | ✅ | ✅ |
| 3 | กด **ส่งและล็อก** → ยืนยัน → ส่งแล้วแก้ไม่ได้ งานหายจากคิว | ✅ | ✅ |
| 4 | กรรมการคนสุดท้ายส่งแล้ว ระบบรวมคะแนนให้อัตโนมัติ (score + ช่วงล่าง–บน) | ✅ | ✅ |

**ลองกดเอง** (ทำ "เตรียมเครื่อง" ด้านล่างก่อน · ถ้าเคย seed ไว้แล้ว ให้ดึงโค้ดใหม่ → `pnpm db:deploy` → `pnpm db:seed` (ข้อมูลเดิมไม่หาย) → เปิด API ใหม่ · รหัสผ่านทุกบัญชี: ดูในไฟล์ `.env`):

*ช่วงที่ 1 — กรรมการให้คะแนน* (งานแต่ละชิ้นในข้อมูลตัวอย่างมอบหมายให้ `reviewer1` และ `reviewer2` · ต้องส่งครบ 2 คน ระบบจึงจะคำนวณผล)
1. เข้าสู่ระบบเป็น `reviewer1@blulens.local` → ไปที่ http://localhost:3100/review
2. กด **เริ่ม** ที่งานหนึ่งรายการ → ดูคลิป → เลือกเกรดให้ครบทุกเกณฑ์
3. กด **ส่งและล็อก** → **ยืนยัน** → งานหายจากคิว
4. ออกจากระบบ → ทำข้อ 1–3 ซ้ำด้วย `reviewer2@blulens.local` บนงานเดียวกัน → ระบบคำนวณผลให้ทันที

*ช่วงที่ 2 — คณะกรรมการตัดสินผล*
5. ออกจากระบบ → เข้าสู่ระบบเป็น `committee@blulens.local` → ไปที่ http://localhost:3100/committee/assessments
6. เปิดงานที่ **รออนุมัติ** → ดูผล (score + ช่วงล่าง–บน) และคะแนนของกรรมการแต่ละคน
7. เลือกทำอย่างใดอย่างหนึ่ง:
   - **อนุมัติ** — ถ้าเป็นงานที่กรรมการเห็นต่างกันมาก (สถานะ "เห็นต่าง") ต้องใส่หมายเหตุอย่างน้อย 5 ตัวอักษร
   - **ส่งกลับ** — ใส่เหตุผลอย่างน้อย 5 ตัวอักษร (เพื่อหากรรมการเพิ่ม) → ในหน้าเดียวกันกด **มอบหมายกรรมการ** → ค้นชื่อแล้วเลือก `reviewer3` → ล็อกอินเป็น `reviewer3@blulens.local` ให้คะแนนที่ `/review` → ระบบคำนวณผลใหม่จากกรรมการ 3 คน แล้วงานกลับมา **รออนุมัติ** (ทดสอบเขียว 3 รอบติด develop `b322b35`)
   - **แก้ไขผล** — เลือกเกรดเอง + เหตุผลอย่างน้อย 20 ตัวอักษร (ผลคำนวณเดิมยังเก็บไว้ในประวัติ · คนที่อยู่ทีมเดียวกับผู้เล่นทำไม่ได้)
   - **ยืนยันผล** — สำหรับผลชั่วคราวที่มาจากกรรมการคนเดียว
8. สถานะในรายการเปลี่ยนตามทันที · เมื่ออนุมัติหรือแก้ไขผลแล้ว เกรดนี้กลายเป็นเกรดทางการของผู้เล่น

**ที่ยังไม่มี:**
- แผงสถิติความสอดคล้องของกรรมการ (Kappa, อคติ) — หลังบ้านกำลังทำ (bl-26-5) แล้วตามด้วยหน้าเว็บ
- ขอความเห็นที่สอง · ชุดคลิปมาตรฐาน · สมาชิกส่งคลิปเอง
- แจ้งเตือนคณะกรรมการทุกคนเมื่อมีการแก้ไขผล (ตอนนี้บันทึกไว้ใน audit log ก่อน)
- หน้ามอบหมายกรรมการ: ยังไม่ได้ทดสอบกรณีกรรมการอยู่ทีมเดียวกับผู้เล่น (ระบบหลังบ้านกันไว้แล้ว) และยังเลือกวันครบกำหนดเองไม่ได้ (ค่าเริ่มต้น 72 ชั่วโมง)
- คลิปในข้อมูลตัวอย่างเป็นไฟล์ทดสอบ ไม่ใช่การเล่นจริง
- ออกแบบให้กรรมการไม่เห็นคะแนนของกรรมการคนอื่น เพื่อให้ประเมินอย่างอิสระ

## ลองกดเองทีละขั้น

**เตรียมเครื่อง (ครั้งแรกครั้งเดียว)** ในโฟลเดอร์ `D:\_work\SourceDev\_code\blulens`:
1. คัดลอก `.env.example` เป็น `.env` (ถ้ายังไม่มี) แล้วตั้ง `SEED_DEMO=1`
   - ถ้ามี `.env` อยู่แล้ว: แก้บรรทัด `DATABASE_URL` ให้ชื่อฐานข้อมูลเป็น `blulens_demo` (ฐานใหม่ที่สะอาด ไม่มีข้อมูลทดสอบ) แล้วทำข้อ 3–4 ใหม่
2. `pnpm install`
3. `pnpm db:deploy` (สร้างฐาน `blulens_demo` ให้เองถ้ายังไม่มี)
4. `pnpm db:seed` (รันซ้ำได้ ไม่สร้างข้อมูลซ้ำ)
5. `pnpm dev` แล้วรอให้ขึ้นครบ

**เส้นทางที่กด** (รหัสผ่านทุกบัญชี: ดูในไฟล์ `.env`):
1. เปิด http://localhost:3100/login → ล็อกอินเป็น **แอดมิน** (อีเมลตาม `SEED_ADMIN_EMAIL` ใน `.env`)
2. ไปที่ `/events/new` → ทำ wizard สร้างรายการแข่ง + ประเภท (เช่น คู่ผสม) → กด **เปิดรับสมัคร**
3. ไปที่ `/admin/events/<รหัสประเภท>/entries/new` → เลือกผู้เล่น 2 คน (เช่น member1 + member6) + เลือกทีมแบบพิมพ์แล้วเลือก (ลองพิมพ์ "บลู" จะเจอ Blue Wing) → บันทึก → กด **ส่งต่อให้คณะกรรมการ**
4. ออกจากระบบ → ล็อกอินเป็น `committee@blulens.local` → ไปที่ `/committee/events/<รหัสประเภท>/entries` → **อนุมัติ** หรือ **ปฏิเสธ** (ปฏิเสธต้องใส่เหตุผลอย่างน้อย 10 ตัวอักษร)
5. ออกจากระบบ → ล็อกอินเป็น `member1@blulens.local` → ไปที่ `/events/<รหัสประเภท>/entries` → เห็นรายชื่อคู่ที่อนุมัติแล้ว

**ข้อมูลตัวอย่างที่มีให้:** แอดมิน (มีสิทธิ์คณะกรรมการด้วย), `committee@blulens.local`, `member1` ถึง `member6@blulens.local` (มีเกรดตัวอย่างแล้ว), กรรมการให้คะแนน `reviewer1` ถึง `reviewer3@blulens.local`, กรรมการสนาม `umpire1@blulens.local` (มีงานประเมินรอให้คะแนน · คลิปเป็นไฟล์ตัวอย่าง ไม่ใช่การเล่นจริง · หน้าให้คะแนนจะประกาศว่า "กดได้" หลังทดสอบผ่าน) · ถ้าเคย seed ไว้ก่อนแล้ว ให้ดึงโค้ดใหม่ รัน `pnpm db:deploy` และ `pnpm db:seed` อีกครั้ง (ข้อมูลเดิมไม่หาย) แล้วเปิด API ใหม่ · ทีม Blue Wing (บลูวิง), Red Phoenix, Green Valley
