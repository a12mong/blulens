## ใช้ได้แล้ววันนี้

**หน้าเว็บที่เปิดได้ (ยังเป็นโครง ไม่มีข้อมูลจริง):**
- `/` หน้าแรก · `/login` หน้าล็อกอิน · `/403` ไม่มีสิทธิ์
- หน้าตามบทบาท (กันสิทธิ์แล้ว): `/me` สมาชิก · `/review` กรรมการประเมิน · `/committee` คณะกรรมการ · `/umpire` กรรมการสนาม · `/admin` แอดมิน

**API ที่ตอบได้:**
- `GET /api/health` → ทำงาน
- ระบบบัญชี (merge แล้ว ผ่านเทสต์อัตโนมัติ): สมัคร, ล็อกอิน, ออกจากระบบ, ต่ออายุ session, ดูข้อมูลตัวเอง (`/api/v1/auth/*`) — พร้อมกันการปลอมคำขอข้ามเว็บ และบันทึก audit
- ฝั่งสัญญา Demo Slice 1 ครบ: รายการแข่ง (สร้าง/ดู/เปลี่ยนสถานะ), ประเภท, ค้นหาผู้เล่น, แนะนำทีม, entry ประเภทคู่ + ส่งต่อ + อนุมัติ/ปฏิเสธ

**วิธีเปิดดูเอง (ทีม dev ตั้งให้):** `pnpm install` → `pnpm db:deploy` → `pnpm db:seed` (ตั้ง `SEED_DEMO=1`) → `pnpm dev` · บัญชีทดลอง: แอดมิน (อีเมลตาม `SEED_ADMIN_EMAIL`), `committee@blulens.local`, `member1..6@blulens.local` — รหัสผ่านอยู่ในไฟล์ `.env` เท่านั้น · ทีมตัวอย่าง: Blue Wing (บลูวิง), Red Phoenix, Green Valley

**ฐานรากที่เสร็จแล้ว (มองไม่เห็นบนหน้าจอ แต่ต้องมีก่อน):**
- โครงฐานข้อมูลครบทุกตาราง (ผู้ใช้ 6 บทบาท, ทีม, การประเมิน + โหมดกรรมการน้อย + ชุดคลิปมาตรฐาน, รายการแข่ง, สาย, รอบแบ่งกลุ่ม, ผลแมตช์ 2 ขั้น)
- สูตรสถิติที่ผ่านการทดสอบแล้ว: ตรวจคะแนนโดด, Cohen's Kappa, Fleiss' Kappa, บันไดเกรด (score/lower/upper), สถิติชุดคลิปมาตรฐาน
- ตัวจับสายเสร็จครบ (seed, bye, กันทีมเดียวกันเจอรอบแรก, ถอนตัว) — 166 เทสต์ผ่าน
- สเปกทั้งหมดได้รับอนุมัติจากเจ้าของแล้ว (สถาปัตยกรรม, การประเมิน, จับสาย, รูปแบบการแข่ง)

## ยังค้าง (ฝั่งหลังบ้าน — Kevin)

- ตัวจับสาย: กรณีเลี่ยงทีมชนไม่ได้ (หาแบบชนน้อยสุด) + แก้บั๊กที่ระบบอ้างว่า "พิสูจน์แล้วว่าน้อยสุด" ทั้งที่ค้นไม่ครบ (bl-18-4b)
