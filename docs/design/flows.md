# Flows — blulens

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

> ทุกแผนภาพเป็น mermaid (เรนเดอร์ใน GitHub). ดูบทบาทและ screen id ใน `README.md`. สถานะ: ร่างรออนุมัติ.

## F0 ภาพรวมวงจรอีเวนต์

```mermaid
flowchart LR
  A[Admin สร้างอีเวนต์ + rubric] --> B[เปิดรับสมัคร]
  B --> C[Member สมัคร + แนบคลิป]
  C --> D[ปิดรับสมัคร]
  D --> E[Committee มอบหมาย Reviewer]
  E --> F[Reviewer ให้คะแนน blind]
  F --> G[ระบบคำนวณ score/lower/upper + kappa + outlier]
  G --> H[Committee ตรวจ dashboard + อนุมัติ]
  H --> I[จับสาย draw: ห้ามทีมเดียวกันเจอกันรอบแรก]
  I --> J[เผยแพร่สายแข่ง/สกอร์บอร์ด]
  J --> K[Guest/Member ดูผล]
```

สถานะอีเวนต์: `draft → registration_open → registration_closed → reviewing → approved → bracket_published → completed` (ชื่อสถานะ TBD-API). ปุ่ม/หน้าจอที่ใช้ได้ผูกกับสถานะนี้.

## F1 สร้างอีเวนต์ (Admin) — S03 → S12 → S04

```mermaid
flowchart TD
  S[S04 รายการอีเวนต์ → ปุ่ม สร้างอีเวนต์] --> W1[ขั้น 1 ข้อมูลพื้นฐาน: ชื่อ วันที่ สถานที่ รูปแบบ ทีม/เดี่ยว]
  W1 --> W2[ขั้น 2 กติกาสมัคร: ช่วงเปิด-ปิด จำนวนสูงสุด ชนิดคลิปที่รับ]
  W2 --> W3[ขั้น 3 Rubric: เลือกเทมเพลต หรือ สร้าง/แก้ใน S12]
  W3 --> W4[ขั้น 4 ทีมกรรมการ: เชิญ Reviewer/Committee]
  W4 --> W5[ขั้น 5 ทบทวน]
  W5 -->|บันทึกร่าง| D[(draft)]
  W5 -->|เปิดรับสมัคร| O[(registration_open)]
  W1 -.ข้อมูลไม่ครบ.-> E1[แสดง error ต่อช่อง ห้ามไปขั้นถัดไป]
  W3 -.rubric น้ำหนักรวม ≠ 100.-> E2[บล็อกถัดไป + บอกส่วนต่าง]
```

## F2 สมัคร + แนบคลิป (Member) — S01 → S02 → S05 → S11

```mermaid
flowchart TD
  A[S01 เลือกอีเวนต์ที่เปิดรับ] --> B{ล็อกอินแล้ว?}
  B -->|ไม่| L[S02 ล็อกอิน/สมัคร] --> C
  B -->|ใช่| C[S05 ฟอร์มสมัคร: ข้อมูลผู้เล่น + ทีม + คลิป]
  C --> K{เลือกชนิดคลิป}
  K -->|ลิงก์| K1[วาง URL → ตรวจรูปแบบ/แหล่งที่อนุญาต → พรีวิว]
  K -->|อัปโหลด| K2[เลือกไฟล์ → ตรวจชนิด/ขนาด/ความยาว → อัปโหลด MinIO พร้อมแถบความคืบหน้า]
  K1 --> R[ทบทวน]
  K2 --> R
  R --> S[ส่งใบสมัคร]
  S --> Z[S11 สถานะ: submitted → รอรีวิว]
  K2 -.เครือข่ายหลุด.-> RS[ลองใหม่/ต่อจากเดิม ไม่เสียฟอร์ม]
  S -.ใบสมัครซ้ำ.-> DUP[แจ้งว่าสมัครแล้ว → ไปแก้ไขใน S11 ก่อนปิดรับ]
```

กติกา: แก้คลิป/ข้อมูลได้จนถึงปิดรับสมัคร; หลังปิดเป็น read-only. ฟอร์มบันทึกร่างอัตโนมัติ (ต่อผู้ใช้ ต่ออีเวนต์).

## F3 Reviewer ให้คะแนน — S06 → S07

```mermaid
flowchart TD
  Q[S06 คิวของฉัน: ทั้งหมด/ยังไม่ทำ/ร่าง/ส่งแล้ว] --> P[S07 เปิดคลิปตัวถัดไป]
  P --> V[เล่นคลิป: เล่น/หยุด/ย้อน 5 วิ/ความเร็ว 0.5x-1x-1.5x]
  V --> I[ให้คะแนนทีละ rubric item: แตะ 1..N + โน้ตหรือ timestamp ได้]
  I --> AS[บันทึกร่างอัตโนมัติ + แสดงความคืบหน้า 3/6 items]
  AS --> SB{ครบทุก item?}
  SB -->|ไม่| I
  SB -->|ใช่| CF[ยืนยันส่ง: สรุปคะแนน]
  CF -->|ส่ง| LK[(locked) → ไปคลิปถัดไป]
  CF -->|ย้อนแก้| I
  V -.คลิปเล่นไม่ได้.-> BR[ปุ่ม รายงานคลิปเสีย → Committee] --> Q
  LK -.ต้องแก้ภายหลัง.-> UN[Committee ปลดล็อกพร้อมเหตุผล → audit log]
```

Reviewer ไม่เห็น `score/lower/upper` ของผลรวมและคะแนนคนอื่นจนกว่า Committee อนุมัติผล (D3).

## F4 Super-Committee: ตรวจและอนุมัติ — S08 → S09

```mermaid
flowchart TD
  D[S08 Dashboard เลือกอีเวนต์] --> A1[ภาพรวม: ความคืบหน้ารีวิว, kappa รวม, จำนวน outlier, รออนุมัติ]
  A1 --> M[Matrix ความสอดคล้องคู่ reviewer]
  A1 --> O[รายการ outlier: ผู้สมัคร × reviewer × item]
  A1 --> PQ[ลิงก์ → S09 คิวอนุมัติ]
  O --> DR[Drill-down: เปิดคลิป + คะแนนทุกคนเทียบกัน]
  DR --> DEC{ตัดสินใจ}
  DEC -->|ยอมรับ| ACC[ปิดธง]
  DEC -->|ขอ re-review| RR[มอบหมาย reviewer เพิ่ม → กลับ F3]
  DEC -->|ตัดคะแนนนี้ออก| EX[ต้องกรอกเหตุผล → audit log]
  PQ --> AP[S09 อนุมัติผลรายผู้สมัคร/ทั้งรอบ]
  AP --> DRAW[สั่งจับสาย S04]
  DRAW --> PUB[เผยแพร่ S10]
```

## F5 สายแข่ง/สกอร์บอร์ดสาธารณะ — S10

```mermaid
flowchart TD
  G[Guest เปิดลิงก์ S10] --> PB{เผยแพร่แล้ว?}
  PB -->|ไม่| EM[หน้าว่าง: ยังไม่เผยแพร่ + วันที่คาดการณ์]
  PB -->|ใช่| TB[แท็บ สายแข่ง / สกอร์บอร์ด / ผลประเมิน]
  TB --> BR[Bracket: คู่ ผล เส้นเชื่อม]
  TB --> SC[Scoreboard: ลำดับ ชื่อ ทีม เกรด band]
  BR --> PF[แตะผู้เล่น → การ์ดผู้เล่น: เกรด lower–upper]
  M[Member ล็อกอิน] --> HL[ไฮไลต์ตัวเอง + ลิงก์ S11]
```

## F6 มอบหมาย Reviewer (Committee) — S04 แท็บ "กรรมการ"

```mermaid
flowchart TD
  A[S04 แท็บ มอบหมาย] --> B[ตารางผู้สมัคร × reviewer]
  B --> C[ปุ่ม จัดอัตโนมัติ: ≥ N reviewer ต่อคลิป, ห้าม reviewer ทีมเดียวกับผู้สมัคร]
  C --> D[ทบทวน/แก้มือ]
  D --> E[ยืนยัน → แจ้ง reviewer]
  B -.conflict ทีมเดียวกัน.-> X[แถวถูกบล็อก พร้อมเหตุผล]
```

## Error ร่วมทุก flow

| กรณี | พฤติกรรม |
|---|---|
| session หมดอายุ | พาไป S02 แล้วกลับหน้าเดิม (ร่างไม่หาย) |
| 403 บทบาทไม่พอ | หน้า "ไม่มีสิทธิ์" + ปุ่มกลับ; ไม่เผยว่ามีทรัพยากรอยู่หรือไม่ |
| 404 | หน้า "ไม่พบ" |
| ออฟไลน์/เครือข่ายหลุด | แบนเนอร์ค้าง; ร่างเก็บในเครื่อง; ส่งซ้ำเมื่อกลับมา (idempotent) |
