## 3. รายละเอียดแต่ละส่วน (ข้อความไทยที่ต้องใช้)

### 3.1 หัวหน้า
- ชื่อ "ธนกร ใจดี" (ใหญ่), รอง "เชียงใหม่ แบด"
- ชิปสถานะ (ไอคอน+ข้อความเสมอ): **✓ "อนุมัติแล้ว"** (เขียว grn) · รหัส `ASM-2026-0142` (ตัวเลข/รหัสใช้ Press Start 2P ได้เล็กน้อยเป็นอัตลักษณ์ ไม่บังคับ; ข้อความไทยใช้ฟอนต์ปกติ)
- บรรทัดรอง: "ประเมินเมื่อ 7 ต.ค. 2569 · กรรมการ 3 คน (ใช้คำนวณ 2 · ตัดออก 1)"

### 3.2 HERO ผลเกรด (จุดขายของหน้า)
- ตัวใหญ่ที่สุดในหน้า: **"S-/S"** (label); ใต้ตัว: "เกรดอยู่ระหว่าง S- ถึง S" และชิป tier **"Standard"** สีม่วง (`pur`) พร้อมข้อความ
- "คะแนน 7.42 ± 0.50" (score ± margin) พร้อม tooltip "ค่าคะแนนต่อเนื่องบนบันไดเกรด 0–15"
- ป้ายชนิดผล `straddle` แปลไทย: "คร่อม 2 ขั้น" (exact = "ตรงขั้น", wide = "ช่วงกว้าง") — ข้อความอธิบายสั้น: "กรรมการเห็นตรงกันว่าอยู่ใกล้ขอบ S-/S"
- **LadderBar (ส่วนประกอบเด่น):** บันได 15 ช่องเรียงแนวนอนจัดกลุ่ม 5 tier (เส้นคั่นบาง + ป้ายชื่อ tier ใต้กลุ่ม); ช่วง `lower`–`upper` (S-, S) ระบายเต็มสี tier Standard; ช่องอื่นสีจาง; **จุดคะแนน 7.42** วางตามตำแหน่งต่อเนื่อง (ลูกศร ▲ + ตัวเลข); แต่ละช่องมีตัวย่อเกรดข้อความเสมอ; สี tier: Rookie `grn`, Beginner `blu`, Standard `pur`, Neutral `org`, Professional `ylw` (ylw เป็นพื้นเท่านั้น ข้อความบนพื้นใช้หมึก)
- animation เบา ๆ ตอนโหลด: แถบช่วงขยายจากกลางออก 400 ms (ปิดเมื่อ `prefers-reduced-motion`)

### 3.3 คลิป
- การ์ด thumbnail 16:9 + ปุ่ม ▶ ใหญ่ + "0:47" มุมล่างขวา + ป้าย "คลิปที่ใช้ประเมิน" · กดแล้ว (ใน mock) เปิด dialog ว่า "ตัวอย่างการนำเสนอ — ไม่มีวิดีโอจริง" หรือเล่นวิดีโอสั้นที่ไม่มีบุคคลถ้ามี (ไม่บังคับ)
- ใต้การ์ด: "1 คลิป · ตรวจโดยกรรมการ 3 คน (แบบ blind: กรรมการไม่เห็นชื่อผู้เล่น)"

### 3.4 คะแนนกรรมการ (ReviewerScoreList)
- 3 แถว: ชื่อ (กรรมการ A/B/C — ในหน้าลูกค้าแสดงเป็นรหัส ไม่ใช้ชื่อจริง) · จุดบนแกนบันไดเดียวกับ LadderBar (แกนย่อ) · ค่า overall + เกรดใกล้เคียง · ชิป: "✓ ใช้คำนวณ" หรือ "⚑ ตัดออก (outlier)"
- แถว C ตัดออก: จุดสีเทา/ขอบประ + ข้อความ "ห่างจากกรรมการส่วนใหญ่ 2.33 ขั้น (เกณฑ์ 2.0)" + tooltip อธิบาย robustZ 9.2
- ปุ่มพับ "ดูคะแนนรายหัวข้อ" → ตาราง 6 หัวข้อ (ฟุตเวิร์ก, ลูกเหนือศีรษะ, หน้าตาข่าย, การรับ, การอ่านเกม/แท็กติก, ความสม่ำเสมอ) × กรรมการ A/B/C แสดงเป็นตัวย่อเกรด; เซลล์ C ขอบประเมินเป็นสีจาง

### 3.5 Kappa
- ชิปใหญ่: "ความสอดคล้องทั้งคณะ 0.68 · ดี" (สีตาม band + ไอคอน: ✓ ดี) พร้อมแถบมาตรา 0–1 มีช่วง แย่/พอใช้/ปานกลาง/ดี/ดีมาก
- คู่ A–B 0.78 ดี · A–C 0.41 ปานกลาง · B–C 0.38 พอใช้ (เมทริกซ์ 3×3 ย่อ ตัวเลขทุกช่อง + ข้อความระดับ)
- หมายเหตุเล็ก: "Kappa ใช้วัดความสอดคล้องของกรรมการ ไม่ใช่คะแนนของผู้เล่น และไม่เข้าสูตรคำนวณเกรด" + "bias กรรมการ C +0.9 ขั้น (ให้สูงกว่าฉันทามติ)"

### 3.6 "ผลนี้คำนวณอย่างไร" (CalcSteps 4 ขั้น แนวนอนบนเดสก์ท็อป / แนวตั้งบนมือถือ)
1. **กรรมการเลือกขั้น** — กรรมการแต่ละคนดูคลิปแล้วเลือกขั้นเกรด (RK1–P+) ต่อ 6 หัวข้อ
2. **ตัดคะแนนโดด** — คะแนนที่ห่างจากมัธยฐานเกิน 2 ขั้นและผิดปกติทางสถิติ (z > 3.5) จะถูกตัดออก: ครั้งนี้ตัดกรรมการ C
3. **เฉลี่ยที่เหลือ** — (7.50 + 7.33) ÷ 2 = **7.42**
4. **ช่วงความมั่นใจ** — ± 0.50 ขั้น → ช่วง 6.92–7.92 → แสดงเป็น **S-/S**
- ลิงก์ "ดูสูตรอย่างละเอียด ▸" เปิด accordion สรุปสูตร (ข้อความอย่างย่อ ไม่ใส่สมการเต็ม) พร้อมบรรทัด "ระบบไม่ปรับคะแนนผู้เล่นตาม Kappa"
