# S01 หน้าแรกสาธารณะ / รายการอีเวนต์

- **วัตถุประสงค์:** ให้ทุกคนเห็นอีเวนต์ที่เปิดอยู่ และพาไปสมัคร (Member) หรือดูสายแข่ง (Guest)
- **บทบาท:** Guest ✓ Member ✓ Reviewer ✓ Committee ✓ Admin ✓ (ทุกคนเห็นหน้าเดียวกัน; ต่างกันที่ปุ่ม CTA และเมนู)
- **Route (เสนอ):** `/`  · **ข้อมูล:** `Event[] {id,title,date,venue,status,registrationDeadline}` (TBD-API)

## Wireframe (mobile 360)

```
┌──────────────────────┐
│ blulens   [เข้าสู่ระบบ]│
├──────────────────────┤
│ อีเวนต์เปิดรับสมัคร   │
│ ┌──────────────────┐ │
│ │ ชื่ออีเวนต์       │ │
│ │ 12 พ.ย. · สนาม X │ │
│ │ [เปิดรับ] ปิด 1 พ.ย.│ │
│ │ [สมัครเลย]        │ │
│ └──────────────────┘ │
│ กำลังแข่ง / ผ่านมาแล้ว │
│ ┌ card ┐ [ดูสายแข่ง] │
└──────────────────────┘
```

## ปุ่มหลักตามบทบาท

| บทบาท | CTA บนการ์ด | เมนูเพิ่ม |
|---|---|---|
| Guest | "ดูสายแข่ง" (ถ้าเผยแพร่) / "ล็อกอินเพื่อสมัคร" | – |
| Member | "สมัคร" / "ใบสมัครของฉัน" | ผลของฉัน |
| Reviewer | + "คิวของฉัน" | คิว |
| Committee/Admin | + "จัดการ" | Dashboard, จัดการอีเวนต์ (Admin: สร้างอีเวนต์) |

## States

| State | แสดง |
|---|---|
| loading | skeleton การ์ด 3 ใบ |
| empty | "ยังไม่มีอีเวนต์" + (Admin) ปุ่ม "สร้างอีเวนต์แรก" |
| error | แบนเนอร์ "โหลดไม่สำเร็จ" + ปุ่มลองใหม่ |
| ปิดรับสมัครแล้ว | ป้าย "ปิดรับ" ปุ่ม CTA disabled พร้อมเหตุผลอ่านได้ |
| ฟิลเตอร์ | แท็บ: เปิดรับ / กำลังแข่ง / จบแล้ว; ไม่มีผลลัพธ์ → "ไม่พบอีเวนต์ในหมวดนี้" |

## หมายเหตุ

- Guest เห็นเฉพาะอีเวนต์ `status ≠ draft`
- Components: C-AppShell, C-EventCard, C-StatusBadge, C-EmptyState, C-ErrorBanner
