# S02 เข้าสู่ระบบ / สมัครสมาชิก

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **วัตถุประสงค์:** ยืนยันตัวตน; สมัครเป็น Member
- **บทบาท:** Guest เท่านั้น (ผู้ล็อกอินแล้วถูกพาไป S01) · **Route:** `/login`, `/register`
- **สมมติฐาน (O6):** Member สมัครเองได้; Reviewer/Committee/Admin เป็นแบบเชิญ (ลิงก์เชิญในอีเมล → ตั้งรหัสผ่าน)

## Wireframe

```
┌──────────────────────┐
│ เข้าสู่ระบบ           │
│ อีเมล    [__________]│
│ รหัสผ่าน [__________]│
│ [ เข้าสู่ระบบ ]       │
│ ยังไม่มีบัญชี? สมัคร  │
│ ลืมรหัสผ่าน           │
└──────────────────────┘
```

## ฟิลด์

| หน้า | ฟิลด์ | กติกา |
|---|---|---|
| login | อีเมล, รหัสผ่าน | ต้องกรอกทั้งคู่ |
| register | ชื่อที่แสดง, อีเมล, รหัสผ่าน (≥ 10 ตัว), ยอมรับเงื่อนไข | ตรวจแบบ inline เมื่อออกจากช่อง |
| invite | ตั้งรหัสผ่าน (บทบาทแสดงเป็นข้อความอ่านอย่างเดียว) | ลิงก์หมดอายุ → หน้า error |

## States / Errors

| กรณี | ข้อความ/พฤติกรรม |
|---|---|
| ข้อมูลผิด | "อีเมลหรือรหัสผ่านไม่ถูกต้อง" (ข้อความเดียว ไม่บอกว่าผิดช่องไหน) |
| บัญชีถูกระงับ | "บัญชีถูกระงับ ติดต่อผู้ดูแล" |
| อีเมลซ้ำ (register) | "อีเมลนี้ถูกใช้แล้ว" + ลิงก์ล็อกอิน |
| ลองผิดหลายครั้ง | ล็อกชั่วคราว แสดงเวลาที่เหลือ |
| submitting | ปุ่ม disabled + spinner |
| หลังสำเร็จ | กลับหน้าที่ตั้งใจไป (`returnTo`) หรือ S01 |

Components: C-TextField, C-Button, C-FormError, C-AppShell (variant: bare)
