# S03 สร้างอีเวนต์ (wizard 5 ขั้น)

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **บทบาท:** Admin เท่านั้น (Committee เห็นผลลัพธ์ใน S04 แต่สร้างไม่ได้) · **Route:** `/admin/events/new`
- **Flow:** ดู F1 ใน `flows.md`

## ขั้นตอนและฟิลด์

| ขั้น | ฟิลด์ | กติกา |
|---|---|---|
| 1 พื้นฐาน | ชื่อ*, คำอธิบาย, วันแข่ง*, สถานที่*, รูปแบบ (เดี่ยว/ทีม)* | ชื่อ ≤ 80 ตัว; วันแข่งต้องหลังวันนี้ |
| 2 สมัคร | เปิด–ปิดรับ*, จำนวนผู้สมัครสูงสุด, ชนิดคลิปที่รับ (ลิงก์/อัปโหลด/ทั้งสอง)*, ความยาวคลิปสูงสุด, ขนาดไฟล์สูงสุด | ปิดรับ > เปิดรับ; ค่าเริ่มต้นตาม D2 |
| 3 Rubric | เลือกเทมเพลต / สร้างใหม่ → ไป S12 แล้วกลับมา | น้ำหนักรวม = 100 |
| 4 กรรมการ | เชิญ Reviewer/Committee ด้วยอีเมล; จำนวน reviewer ต่อคลิป (≥ 2; แนะนำ ≥ 3 สำหรับ Fleiss) | ต้องมี Committee ≥ 1 |
| 5 ทบทวน | สรุปทุกขั้น + ปุ่ม [บันทึกร่าง] [เปิดรับสมัคร] | เปิดรับสมัครได้เมื่อขั้น 1–4 ผ่าน |

## States

| State | พฤติกรรม |
|---|---|
| pristine | ปุ่มถัดไป active; ตรวจเมื่อกด |
| invalid | error ใต้ช่อง + สรุปด้านบน, โฟกัสช่องแรกที่ผิด |
| autosave | "บันทึกร่างแล้ว HH:MM" |
| ออกจากหน้ากลางคัน | dialog ยืนยัน (ร่างเก็บไว้) |
| เปิดรับสมัครสำเร็จ | toast + ไป S04 |
| API error | แบนเนอร์ + คงค่าในฟอร์ม |
| ผู้ใช้ไม่ใช่ Admin | 403 |

Components: C-Stepper, C-TextField, C-DateRangeField, C-RadioGroup, C-RubricSummary, C-InviteList, C-Button
