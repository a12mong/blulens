# S04 จัดการอีเวนต์

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **บทบาท:** Admin (ทุกแท็บ) · Committee (ดูทุกแท็บ; แก้ได้เฉพาะ "กรรมการ/มอบหมาย", "จับสาย", "เผยแพร่") · อื่น ๆ 403
- **Route:** `/admin/events/:id` · แท็บมี deep link

## Layout

```
┌──────────────────────────────────────┐
│ ชื่ออีเวนต์  [registration_open]       │
│ ภาพรวม│ผู้สมัคร│กรรมการ/มอบหมาย│Rubric│สาย│ตั้งค่า │
├──────────────────────────────────────┤
│ (เนื้อหาแท็บ)                         │
└──────────────────────────────────────┘
```

## แท็บ

| แท็บ | เนื้อหา | ใคร |
|---|---|---|
| ภาพรวม | สถานะ, ตัวนับ (สมัคร/ส่งคลิป/รีวิวเสร็จ), ปุ่มเปลี่ยนสถานะที่ทำได้ | A, C ดู |
| ผู้สมัคร | ตารางผู้สมัคร: ชื่อ, ทีม, ชนิดคลิป, สถานะคลิป (ok/เสีย), ตัวกรอง | A, C |
| กรรมการ/มอบหมาย | ดู F6: ตารางผู้สมัคร × reviewer, จัดอัตโนมัติ/แก้มือ, conflict บล็อก | A, C แก้ |
| Rubric | อ่านอย่างเดียวหลังเปิดรับสมัคร (แก้ได้เฉพาะ draft) → ลิงก์ S12 | A |
| สาย | ปุ่ม "จับสาย" (เปิดเมื่อสถานะ approved), พรีวิวสาย, ปุ่ม "สุ่มใหม่" (ต้องยืนยัน + เหตุผล), ปุ่ม "เผยแพร่" | C, A |
| ตั้งค่า | แก้ข้อมูลอีเวนต์, ลบ/ยกเลิกอีเวนต์ (Admin; ต้องพิมพ์ชื่อยืนยัน) | A |

## การเปลี่ยนสถานะ (ปุ่มต้องบอกผลที่ตามมา)

| จาก → ไป | ปุ่ม | ข้อกำหนดก่อน |
|---|---|---|
| draft → registration_open | เปิดรับสมัคร | wizard ครบ |
| registration_open → closed | ปิดรับ | – (หรือถึงเวลา) |
| closed → reviewing | เริ่มรีวิว | มอบหมาย reviewer ครบทุกคลิป |
| reviewing → approved | (S09) อนุมัติผล | outlier ที่ติดธงถูกตัดสินครบ |
| approved → bracket_published | จับสาย + เผยแพร่ | มีผู้เข้าแข่ง ≥ 2 |

## States

| State | แสดง |
|---|---|
| ปุ่มถูกปิด | ปิดพร้อมข้อความเหตุผล (เช่น "ยังมี 4 คลิปไม่มี reviewer") |
| ผู้สมัครว่าง | "ยังไม่มีผู้สมัคร" + ปุ่มคัดลอกลิงก์สมัคร |
| จับสายล้มเหลว (ไม่มีวิธีจัดที่ไม่ชนทีมเดียวกัน) | error สีแดง + ไอคอน อธิบายทีมที่ชน + ทางเลือก: ปรับกลุ่ม/ยกเว้นด้วยเหตุผล (Committee) — พฤติกรรมตาม bl-04 |
| ยืนยันการกระทำเสี่ยง | dialog 2 ขั้น + บันทึก audit |
| โหลด/ผิดพลาด | skeleton / แบนเนอร์ลองใหม่ |
