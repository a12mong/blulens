# S05 ฟอร์มสมัคร + คลิป (mobile-first)

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **บทบาท:** Member (และบทบาทสูงกว่าที่ไม่ได้ขัดกฎ conflict) · Guest ถูกชวนล็อกอิน (F2) · **Route:** `/events/:id/register`
- **เงื่อนไข:** อีเวนต์ `registration_open` เท่านั้น; แก้ไขได้จนปิดรับ

## ฟิลด์

| ฟิลด์ | บังคับ | กติกา |
|---|---|---|
| ชื่อที่แสดง | ✓ | ดึงจากโปรไฟล์ แก้ได้ |
| ทีม/สังกัด (TBD-API, O7) | ✓ ถ้ารูปแบบทีม | ใช้ในกติกา draw ห้ามทีมเดียวกันเจอกันรอบแรก — แสดงข้อความอธิบายตรงช่อง |
| ติดต่อ (โทร) | – | |
| **คลิป** | ✓ | เลือก 1 ใน: ลิงก์ / อัปโหลด (ตามที่อีเวนต์เปิด) |
| ยอมรับกติกา/ความยินยอมใช้คลิปประเมิน | ✓ | checkbox |

## C-ClipInput (แท็บสลับ ลิงก์ | อัปโหลด)

```

```

## States ของคลิป

| State | ลิงก์ | อัปโหลด |
|---|---|---|
| idle | ช่องว่าง + ตัวอย่างลิงก์ที่รับ | พื้นที่วางไฟล์ |
| validating | spinner "กำลังตรวจลิงก์" | ตรวจชนิด/ขนาด/ความยาวฝั่งเครื่องก่อนส่ง |
| ready | แสดงชื่อแหล่ง + พรีวิว | ชื่อไฟล์ + ขนาด + พรีวิว (C-ClipPlayer) |
| uploading | – | แถบความคืบหน้า + ยกเลิก; ปุ่มส่งฟอร์ม disabled |
| error | "แหล่งนี้ไม่รองรับ" / "ลิงก์เป็นส่วนตัวหรือเปิดไม่ได้" / "URL ไม่ถูกต้อง" | "ไฟล์ใหญ่เกิน 200MB" / "ยาวเกิน 90 วินาที" / "ชนิดไฟล์ไม่รองรับ" / "อัปโหลดหลุด — [ลองใหม่]" |
| processing (หลังอัปโหลด) | – | "กำลังประมวลผลคลิป" (ป้ายเหลือง) → ok/เสีย; ส่งฟอร์มได้ ผู้ตรวจจะเห็นเมื่อ ok |

## States ของฟอร์ม

| State | พฤติกรรม |
|---|---|
| ใหม่ | ฟอร์มเปล่า, autosave ร่าง |
| มีใบสมัครแล้ว | โหมดแก้ไข + แสดงสถานะ; ปุ่ม "บันทึกการแก้ไข" |
| ปิดรับแล้ว | read-only + แบนเนอร์ |
| เต็ม | "ผู้สมัครครบจำนวน" (ปุ่ม disabled) |
| ส่งสำเร็จ | หน้ายืนยัน + ลิงก์ S11 |
| ส่งไม่สำเร็จ | คงข้อมูล ไม่ต้องอัปโหลดคลิปใหม่ |
| Conflict | ผู้ใช้ที่เป็น Reviewer ของอีเวนต์นี้สมัครไม่ได้: "คุณเป็นกรรมการของอีเวนต์นี้" |

## Mobile

- คอลัมน์เดียว, ปุ่มส่งยึดล่างจอ (sticky), เป้า ≥ 44px; ใช้กล้อง/แกลเลอรีของเครื่องผ่าน input ไฟล์
- เห็นความคืบหน้าอัปโหลดแม้เลื่อนหน้า (แถบสรุปด้านบน)

Components: C-TextField, C-ClipInput, C-ClipPlayer, C-ProgressBar, C-FormError, C-Button(sticky), C-Checkbox
