# S06 คิวของ Reviewer

- **บทบาท:** Reviewer (เห็นเฉพาะที่ได้รับมอบหมาย) · Committee/Admin (เห็นเฉพาะที่ตนเองได้รับมอบหมายในหน้านี้; ภาพรวมทั้งหมดอยู่ S08)
- **Route:** `/review` · mobile-first

## Blind rule

การ์ดแสดงเฉพาะรหัสนิรนาม เช่น "คลิป #A-014" · ความยาว · สถานะ — **ไม่แสดงชื่อ/ทีม/รูป**

## States

| State | แสดง |
|---|---|
| ปกติ | รายการเรียงตามกำหนดส่ง แล้วตามความคืบหน้า |
| empty (ยังไม่มีมอบหมาย) | "ยังไม่มีคลิปให้ตรวจ — คุณจะได้รับแจ้งเมื่อมีการมอบหมาย" |
| empty (ทำครบ) | "ตรวจครบแล้ว 🎉" (ไม่ใช้ emoji จริง — ใช้ไอคอน) + สรุปจำนวน |
| คลิปเสีย | ป้ายแดง "คลิปเล่นไม่ได้ (รายงานแล้ว)" ปุ่ม disabled |
| ถูกปลดล็อกโดย Committee | ป้าย "ต้องแก้ไข" + เหตุผลที่ Committee ระบุ |
| เลยกำหนด | ไอคอน + ข้อความ "เลยกำหนด" (ไม่ใช้สีอย่างเดียว) |
| error | แบนเนอร์ลองใหม่ |
