# S07 หน้าให้คะแนน (หัวใจของระบบ — mobile-first)

- **บทบาท:** Reviewer ที่ได้รับมอบหมายคลิปนั้น; Committee/Admin ที่ได้รับมอบหมายหรือเปิดแบบ "ดูอย่างเดียว" จาก S08 (ไม่มีปุ่มส่งคะแนนแทนผู้อื่น)
- **Route:** `/review/:assignmentId` · **กฎ:** blind (D3), ห้ามมีชื่อ/ทีมของผู้สมัคร

## พฤติกรรม

| เรื่อง | กติกา |
|---|---|
| เล่นคลิป | embed สำหรับลิงก์ภายนอก / player สำหรับ MinIO; ปุ่มย้อน 5 วิ; ความเร็ว 0.5/1/1.5; คีย์ลัดบน desktop: Space, ←/→ |
| ให้คะแนน | C-ScoreInput แบบปุ่มกลุ่ม (segmented 1..N), แตะเลือก, แตะซ้ำไม่ยกเลิก (ใช้ปุ่ม "ล้าง"); ข้อความอธิบายระดับ (anchor) ขึ้นเมื่อเลือก/โฟกัส |
| โน้ต | ต่อ item (ไม่บังคับ; บังคับถ้า Committee ตั้ง "ต้องมีเหตุผลเมื่อให้ระดับสุดขอบ" — ตัวเลือกใน S12) |
| ปักเวลา | ปุ่ม "ปักเวลาปัจจุบัน" แนบ timestamp กับโน้ต |
| บันทึกร่าง | อัตโนมัติทุกครั้งที่เปลี่ยนค่า (debounce); แสดง "บันทึกแล้ว HH:MM" / "กำลังบันทึก" / "บันทึกไม่ได้ — จะลองใหม่" |
| ส่ง | เปิดเมื่อครบทุก item; dialog สรุป (คะแนนต่อ item) ปุ่ม "ส่งและล็อก" / "กลับไปแก้" |
| หลังส่ง | โหมด locked: แสดงคะแนนที่ส่งอย่างเดียว (ไม่เห็นผลรวม/คนอื่น); ปุ่ม "คลิปถัดไป" |

> **ไม่มีการแสดง score/lower/upper ให้ Reviewer ก่อนอนุมัติผล.** ช่วงผลรวมแสดงใน S08/S09 (Committee) และ S10/S11 (หลังเผยแพร่). UI ผลลัพธ์ใช้ C-GradeBand.

## States

| State | พฤติกรรม |
|---|---|
| loading | skeleton player + rubric |
| draft | ตามด้านบน |
| ครบ พร้อมส่ง | ปุ่ม "ส่ง" active + ไฮไลต์ |
| submitting | ปุ่ม disabled |
| locked | ฟิลด์ read-only + ป้าย "ส่งแล้ว" |
| unlocked-by-committee | แบนเนอร์เหลือง + เหตุผล + ฟิลด์แก้ได้; ส่งใหม่แล้วล็อกอีกครั้ง |
| คลิปเล่นไม่ได้ | แทนที่ player ด้วยข้อความ + ปุ่ม "รายงานคลิปเสีย" และ "เปิดแหล่งเดิมในแท็บใหม่"; ห้ามส่งคะแนนจนกว่า Committee แก้ |
| ออฟไลน์ | แบนเนอร์; ร่างเก็บในเครื่อง; ส่งไม่ได้จนกลับออนไลน์ |
| ชนกัน (แก้จาก 2 อุปกรณ์) | แจ้ง "มีการแก้ไขใหม่กว่า" ให้เลือกใช้ค่าไหน |
| ไม่มีสิทธิ์/ไม่ได้ถูกมอบหมาย | 403 |
| conflict (ผู้ตรวจเป็นเจ้าของคลิป/ทีมเดียวกัน) | บล็อกที่ระดับมอบหมาย; ถ้าหลุดมา แสดง 403 + ข้อความ |

## Accessibility

- C-ScoreInput เป็น radio group (ลูกศรเปลี่ยนค่า); ไม่พึ่งสีอย่างเดียว (แสดงตัวเลข + เครื่องหมาย ✓)
- ปุ่มควบคุม player ≥ 44×44, มี label; รองรับ captions ถ้ามี

Components: C-ClipPlayer, C-ScoreInput, C-RubricItemCard, C-ProgressBar, C-StickyActionBar, C-ConfirmDialog, C-ErrorBanner, C-SaveIndicator
