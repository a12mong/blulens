# S08 Dashboard Super-Committee

- **บทบาท:** Committee, Admin เท่านั้น · **Route:** `/committee/events/:id`
- **ข้อมูลสถิติทั้งหมดมาจาก API (bl-03); UI แสดงอย่างเดียว ห้ามคำนวณ kappa/outlier เอง**
- เกณฑ์ดี/เตือน/แย่ของ kappa = O9 (รอ bl-03). ใน spec ใช้ชื่อ `agreementLevel: good|warn|poor` เป็นตัวแทน

## ส่วนประกอบ

| ส่วน | ข้อมูล | หมายเหตุ |
|---|---|---|
| C-StatTile × 4 | ความคืบหน้ารีวิว, kappa รวม (+ระดับ), จำนวน outlier, รออนุมัติ | กดแล้วเลื่อน/กรองไปส่วนที่เกี่ยวข้อง |
| C-AgreementMatrix | kappa ต่อคู่ reviewer (Cohen) + kappa รวม (Fleiss เมื่อ n>2) | แต่ละช่องมีตัวเลขเสมอ (ไม่ใช้สีอย่างเดียว) + ระดับเป็นไอคอน/ข้อความ; แตะช่อง → ดูรายการที่ไม่ตรงกัน |
| C-OutlierTable | คลิป(นิรนาม), reviewer, item, คะแนนที่ให้, ค่ากลางของคนอื่น, ส่วนเบี่ยงเบน, สถานะ (open/accepted/re-review/excluded) | กดแถว → drill-down |
| C-ResultsTable | ผู้สมัคร, `score`, `C-GradeBand(lower,upper)`, จำนวนรีวิว, ธง | จัดเรียง/ส่งออก CSV (TBD) |
| Drill-down (drawer/หน้า) | C-ClipPlayer + คะแนนทุก reviewer ต่อ item เทียบกัน + โน้ต | ปุ่มตัดสิน: ยอมรับ / ขอ re-review / ตัดออก (ต้องมีเหตุผล) |

## Roles และความเป็นส่วนตัว

- Committee เห็นตัวตน reviewer (R1.. = ชื่อจริง) และคลิปแบบระบุตัวผู้สมัคร; Reviewer ไม่เห็นหน้านี้
- Committee ที่เป็นเจ้าของคลิป/ทีมเดียวกัน: ข้อมูลของผู้สมัครคนนั้นถูกซ่อน/ปิดการตัดสิน (conflict)
