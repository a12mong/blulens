# S10 สายแข่ง / สกอร์บอร์ดสาธารณะ (สไตล์ pixel 'bad8bit')

- **บทบาท:** ทุกคน รวม Guest · **Route:** `/events/:id/bracket` (และ `/tv` โหมดจอใหญ่ สำหรับ hall TV — ตัวเลือก)
- **ข้อมูล:** เฉพาะที่เผยแพร่แล้ว (D4). Guest เห็น: ชื่อแสดง, ทีม, คู่แข่ง, ผลแมตช์, เกรด band (lower–upper). **ไม่เห็น:** คะแนนต่อ rubric, คะแนนต่อ reviewer, คลิป, ข้อมูลติดต่อ
- Member ที่ล็อกอิน: แถว/ช่องของตนเองถูกไฮไลต์ + ลิงก์ไป S11

## ภาษาภาพ (ตาม bad8bit style guide / design tokens)

| เรื่อง | กติกา |
|---|---|
| ธีม | ใช้โทเคน **night** เป็นพื้นของ S10 (`bg #1c1926`, `panel #262234`, `panel-2 #2f2a40`) ทั้งเมื่อแอปอยู่โหมด daylight (S10 เป็นหน้าจอ "แสดงผล" แบบเกม) — ตามคำแนะนำ D1 |
| ตัวอักษร | Press Start 2P สำหรับ: ตัวเลขคะแนน, หัวรอบ (R1/QF/SF/F), อันดับ, ตัวย่อเกรด. ข้อความไทย/ชื่อใช้ฟอนต์ข้อความปกติ (ห้าม pixel font กับไทย) |
| เส้น/กรอบ | เส้นสายแบบมุมฉาก 2px, ไม่มีมุมโค้ง; กรอบการ์ดผู้เล่นใช้ `line-3`; ใช้ "เงาแข็ง" 3px ได้บนวัตถุแบบเกมเท่านั้น (ตาม T5: ห้ามบนกรอบ UI ทั่วไป) |
| ภาพ | Avatar/badge ขนาดเป็นพหุคูณ 16 (32/64) `image-rendering: pixelated`; ไอคอนผู้ชนะ = badge champion/runner-up (ตาม badges-v1) |
| สี | แพ้/ชนะสื่อด้วย **ข้อความ + ตำแหน่ง + ไอคอน** ไม่ใช่สีล้วน; `grn/red` ใช้เสริมเท่านั้น |
| Motion | ไม่เคลื่อนไหวถ้า `prefers-reduced-motion`; (เลือกได้) กระพริบเบา ๆ บนแมตช์ที่กำลังแข่ง |

## แท็บ

| แท็บ | เนื้อหา |
|---|---|
| สายแข่ง | C-Bracket: คู่ ผลแมตช์ สถานะ (รอ/กำลังแข่ง/จบ), ผู้ชนะ; กฎ "ทีมเดียวกันไม่เจอรอบแรก" อธิบายใน tooltip/ข้อความท้ายหน้า |
| สกอร์บอร์ด | C-Scoreboard: อันดับ, ชื่อ, ทีม, C-GradeBand, ผล W/L (ถ้ามี) |
| ผลประเมิน | รายชื่อ + เกรด band ตามลำดับ (จากผลที่อนุมัติ) |

## States

| State | แสดง |
|---|---|
| ยังไม่เผยแพร่ | หน้า empty แบบ pixel: "สายแข่งยังไม่ประกาศ" + ปุ่มกลับ; Committee/Admin เห็นปุ่ม "ไปจัดการ" |
| กำลังโหลด | skeleton กล่องแมตช์ |
| BYE | ช่องแสดง "BYE" (ข้อความ + ไอคอน) |
| ผู้เล่นถอนตัว | แถวขีดฆ่า + "ถอนตัว" (ข้อความ) |
| ผลแมตช์ยังไม่มี | "—" |
| เผยแพร่ซ้ำ/สุ่มใหม่ | แบนเนอร์ "สายถูกปรับปรุง HH:MM" |
| error | แบนเนอร์ + ลองใหม่; แสดงข้อมูลที่แคชไว้ถ้ามี |
| รีเฟรชอัตโนมัติ | ทุก 30 วิ เมื่อสถานะ `bracket_published`; หยุดเมื่อ `completed` |
| ผู้ชมแบบ a11y | ตารางข้อความสำรอง (visually-hidden) ของทุกแมตช์ ให้ screen reader อ่านได้ |
