# S11 ผลของฉัน / ใบสมัครของฉัน

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **บทบาท:** Member (เห็นเฉพาะของตนเอง) · Reviewer/Committee/Admin เห็นในฐานะผู้สมัครของตน · **Route:** `/me`

## ส่วนประกอบ

| ส่วน | เนื้อหา |
|---|---|
| รายการใบสมัคร | อีเวนต์, สถานะ (submitted / ในการรีวิว / ผลประกาศ / ถอนตัว), ปุ่ม แก้ไข (ก่อนปิดรับ) / ถอนตัว |
| สถานะคลิป | ok / กำลังประมวลผล / เสีย (+ปุ่มอัปโหลดใหม่ถ้ายังไม่ปิดรับ) |
| ผลการประเมิน | หลังเผยแพร่เท่านั้น: `C-GradeBand` (lower–upper) + `score` + คำอธิบายอ่านง่ายของ band |
| ตำแหน่งในสาย | ลิงก์ไป S10 พร้อมไฮไลต์ |

## Blind / ความเป็นส่วนตัว

- Member **ไม่เห็นตัวตน reviewer และคะแนนรายคน**; อาจเห็นคะแนนต่อ rubric item แบบรวม (ค่ากลาง) ถ้าเจ้าของอนุญาต (O4 — ค่าเริ่มต้น: ไม่เห็น)
- ก่อนเผยแพร่: แสดง "อยู่ระหว่างตรวจ" เท่านั้น ไม่เผยจำนวนรีวิว

## States

| State | แสดง |
|---|---|
| ไม่มีใบสมัคร | "คุณยังไม่ได้สมัครอีเวนต์ใด" + ลิงก์ S01 |
| รอรีวิว | ไทม์ไลน์ 4 ขั้น: ส่งแล้ว → กำลังตรวจ → อนุมัติ → ประกาศ (ขั้นปัจจุบันมีข้อความ ไม่ใช้สีอย่างเดียว) |
| คลิปเสีย | แบนเนอร์ action ที่ต้องทำ |
| ผลประกาศแล้ว | การ์ดผลลัพธ์ + ปุ่มแชร์ลิงก์ S10 |
| ถอนตัวแล้ว | read-only + ป้าย |
| error/loading | มาตรฐาน |
