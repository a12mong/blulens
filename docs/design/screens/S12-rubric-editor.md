# S12 ตัวแก้ Rubric

> ⚠ **ถูกกำกับโดย `contract-alignment.md` (v2)** — ข้อความที่ขัดกับไฟล์นั้น (สเกล 15 ขั้น, upload-only, สิทธิ์ Admin/Committee, outlier, สถานะรีวิว/อีเวนต์, การมองเห็นเกรดของ Guest) ให้ยึดไฟล์นั้น

- **บทบาท:** Admin แก้ได้ · Committee ดูอย่างเดียว · อื่น ๆ 403 · **Route:** `/admin/rubrics/:id`
- **กฎ:** แก้ได้เฉพาะ rubric ที่ยังไม่ผูกกับอีเวนต์ที่เปิดรับสมัครแล้ว (เปิดแล้ว = ล็อก; ต้อง "ทำสำเนาเป็นเวอร์ชันใหม่")
- **ข้อจำกัด:** โครงสร้างต้องตรงกับ bl-03 (สเกล, น้ำหนัก, anchor) — ฟิลด์ที่ระบุคือข้อเสนอ TBD-API

## ฟิลด์ต่อ Rubric Item

| ฟิลด์ | กติกา |
|---|---|
| ชื่อ item* | ≤ 40 ตัว (เช่น "ฟอร์มการตี", "footwork") |
| น้ำหนัก (%)* | ผลรวมทุก item = 100 (แสดงยอดรวมสด + ส่วนต่าง) |
| สเกล | min–max จำนวนเต็ม (ค่าเริ่มต้น 1–5) |
| คำอธิบายระดับ (anchor) | ต่อระดับ ≥ ระดับต่ำสุด/กลาง/สูงสุด (ตามเทมเพลต) — ใช้แสดงใน S07 |
| บังคับโน้ตเมื่อสุดขอบ | toggle |

## Wireframe

```
 Rubric: มาตรฐานแบดมินตัน v1     [ทำสำเนา] [บันทึก]
 ┌ 1 ฟอร์มการตี   น้ำหนัก [30]%  สเกล 1–5 ┐ ↑↓ ✕
 │  1: …   3: …   5: …                    │
 └────────────────────────────────────────┘
 [+ เพิ่ม item]       รวม 100% ✓
```

## States

| State | แสดง |
|---|---|
| ใหม่/ว่าง | เริ่มจากเทมเพลต หรือเปล่า |
| น้ำหนักรวม ≠ 100 | บันทึกไม่ได้ + "ขาด 10%" |
| ถูกใช้โดยอีเวนต์ที่เปิดแล้ว | read-only + ปุ่ม "ทำสำเนา" |
| ลบ item ที่มีรีวิวแล้ว | ห้าม (ปุ่มปิด + เหตุผล) |
| ซ้ำชื่อ item | error ต่อช่อง |
| ตัวอย่าง | แท็บ "พรีวิว" แสดงหน้าตาเหมือน S07 |
