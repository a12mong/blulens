# S13 แมตช์ของฉัน + กรอกผล (Umpire, mobile-first)

> ⚠ ยึด `../contract-alignment.md` และ `../v3-umpire-grading-v2.md` เมื่อขัดกัน · อ้างอิง `docs/specs/tournament-format.md` §5/§5.1 · สถานะ: ร่าง [WAITING FOR OWNER APPROVAL]

- **บทบาท:** Umpire (เฉพาะแมตช์ที่มอบหมายให้ตนหรืออยู่ในสนามของตน) · Committee (กรอกแทนได้ → `confirmed` ทันที + audit) · อื่น ๆ 403 · **Route:** `/umpire`, `/umpire/matches/:id`
- ห้าม Umpire กรอกแมตช์ที่ตนเป็นผู้เล่น (ปุ่มปิด + เหตุผล); ถ้ามีทีมร่วมกับผู้เล่น → กรอกได้แต่แสดงป้าย "แจ้ง Committee: ทีมเดียวกัน" (flag `UMPIRE_TEAM_CONFLICT`)

## กรอกผล (S13b)

- หัวข้อ: คู่แข่ง + ป้ายรูปแบบแมตช์ (เช่น "2 เกม × 15 แต้ม ไม่มีดิวส์" / "2 ใน 3 เกม × 21 ดิวส์ถึง 30") ดึงจากการตั้งค่ารายการ
- ต่อเกม: ตัวนับแต้มสองฝั่ง ปุ่ม +/− ≥ 56px และช่องตัวเลข; ผู้ชนะเกมแสดงด้วยข้อความ+ไอคอน
- ตรวจตามรูปแบบแบบสด: `fixed_games` ต้องครบทุกเกม; `best_of` หยุดเมื่อมีผู้ชนะ ห้ามกรอกเกินและซ่อนเกมที่ไม่ต้องกรอก; แต้มผิดกติกา → error ใต้เกม ปิดปุ่มส่ง; รอบน็อคเอาท์ห้ามเสมอ
- สรุปผล: ผู้ชนะ/เสมอ + ผลต่างแต้ม; ปุ่ม "รายงานผล" → dialog ยืนยันสรุป
- ปุ่มเสริม: ไม่มาแข่ง/ถอนตัว (walkover) ต้องเลือกเหตุผล (TBD-API)

## States

| State | แสดง |
|---|---|
| scheduled | ฟอร์มว่าง |
| reported | แสดงผลที่รายงาน + ป้าย "รอ Committee ยืนยัน"; Umpire แก้ได้จนกว่ายืนยัน |
| returned (ตีกลับ) | แบนเนอร์เหลือง + เหตุผลของ Committee; ฟอร์มเปิดกรอกใหม่ |
| confirmed | read-only ป้าย "ยืนยันแล้ว" |
| ไม่มีแมตช์ | "ยังไม่มีแมตช์ที่มอบหมาย" |
| ออฟไลน์ | เก็บฉบับร่างในเครื่อง + แจ้ง "ยังไม่ได้ส่ง" (สนามมักสัญญาณอ่อน); ส่งเมื่อกลับมา (idempotent) |
| ชนกัน (Committee กรอกไปแล้ว) | "แมตช์นี้ถูกยืนยันแล้ว" |
| แมตช์ที่ตนเป็นผู้เล่น | ปุ่มปิด + เหตุผล |
