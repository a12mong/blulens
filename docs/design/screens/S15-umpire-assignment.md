# S15 มอบหมาย Umpire และสนามต่อรายการ (Committee)

> ⚠ ยึด `../contract-alignment.md` และ `../v3-umpire-grading-v2.md` เมื่อขัดกัน · อ้างอิง `tournament-format.md` §5.1 · สถานะ: ร่าง [WAITING FOR OWNER APPROVAL]

- **บทบาท:** Committee แก้ · Admin ดูอย่างเดียว · **Route:** `/committee/events/:id/umpires` (แท็บใน S04)
- Umpire เป็นบทบาทที่ถูกกำหนดในระบบผู้ใช้; หน้านี้เลือกจากผู้ที่มีบทบาท Umpire

```
 สนามของรายการนี้:  [สนาม 1][สนาม 2][+ เพิ่มสนาม]
 ┌ สนาม 1 ─────────────────────┐
 │ Umpire: [สมศักดิ์ ✕] [+ เพิ่ม]   │
 │ แมตช์ 12 (กลุ่ม A,B)             │
 └──────────────────────────────┘
 แมตช์ที่ยังไม่มี Umpire: 3  [มอบหมายอัตโนมัติ]
 ตารางแมตช์ × Umpire (override รายแมตช์)
```

| เรื่อง | พฤติกรรม |
|---|---|
| มอบหมาย | ต่อสนาม (Umpire กรอกได้ทุกแมตช์ในสนาม) และ/หรือรายแมตช์ |
| conflict | Umpire ที่เป็นผู้เล่นในแมตช์ → เลือกไม่ได้ (disabled+เหตุผล); ทีมเดียวกับผู้เล่น → เลือกได้พร้อมคำเตือน |
| แมตช์ไม่มี Umpire | แบนเนอร์ + จำนวน (คำเตือน ไม่บล็อก — Committee กรอกแทนได้) |
| ว่าง (ยังไม่มีสนาม) | "เพิ่มสนามเพื่อมอบหมาย Umpire" |
| บันทึก | autosave + ป้ายสถานะ; แจ้ง Umpire เมื่อถูกมอบหมาย (TBD-API) |
| ไม่มีสิทธิ์ | 403 |
