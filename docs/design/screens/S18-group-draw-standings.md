## ส่วนประกอบ

| ส่วน | เนื้อหา |
|---|---|
| ตั้งค่ารูปแบบ | `type` (knockout / groups_knockout), ขนาดกลุ่ม, ผ่านต่อกลุ่ม, อันดับ 3 ที่ดีที่สุด, รูปแบบแมตช์รอบกลุ่ม/น็อคเอาท์, แต้ม ชนะ/เสมอ/แพ้ — แสดงสรุปอ่านง่าย ("2 เกม × 15 แต้ม ไม่มีดิวส์") |
| จับกลุ่ม | ปุ่ม "จับกลุ่ม" → พรีวิวกลุ่ม (GroupCard ต่อกลุ่ม: entry + ทีม + เกรด เฉพาะ Committee เห็น) · ข้อความเตือนเมื่อเลี่ยงทีมเดียวกันไม่ได้ (ไอคอน+ข้อความ ไม่ใช้สีอย่างเดียว) · "สุ่มใหม่" ต้องยืนยัน+เหตุผล · "ล็อก/เผยแพร่" ตามสถานะ draw (preview/published/superseded/locked) |
| ตารางคะแนนกลุ่ม | ต่อกลุ่ม: อันดับ แข่ง ชนะ/เสมอ/แพ้ ผลต่างแต้ม แต้ม; แสดงเฉพาะผล `confirmed` + ป้ายจำนวนแมตช์ที่ยังรอยืนยัน; เสมออันดับ → แสดงเกณฑ์ตัดสินที่ใช้ (ข้อความ) |
| ยืนยันผลรอบกลุ่ม | เปิดเมื่อทุกแมตช์ `confirmed/void`; อธิบายผลลัพธ์ (ผู้เข้ารอบ) ก่อนกดยืนยัน |
| พรีวิวน็อคเอาท์ | BracketPreview ตามสายที่จะสร้าง + ผู้เข้ารอบจากกลุ่มใด + ธง/คำเตือน (เช่น เลี่ยงกลุ่มเดียว/ทีมเดียวกันไม่ได้) |
