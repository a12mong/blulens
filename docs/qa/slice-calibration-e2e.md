# Gate: ชุดคลิปมาตรฐาน (calibration) ฝั่ง Committee

ไฟล์: `apps/web/e2e/slice-calibration.spec.ts` · ต้องมี MinIO · ไม่ใช้ SQL · งานมอบหมาย + ตารางผล (bl-34-3) จะเพิ่มใน gate ถัดไป

| ขั้น | ตรวจ | ผลที่คาด |
|---|---|---|
| K1 | สร้างชุดจาก UI | POST 201, การ์ดปรากฏ (ชื่อ+รอบ), เปิดแล้วเป็น "ฉบับร่าง" ไม่มีคลิป |
| K2 | อัปโหลดคลิปอ้างอิง (ต้องเลือกเกรดก่อน ปุ่มเลือกวิดีโอจึงใช้ได้) | complete 200, คลิปพร้อมใช้, viewUrl เล่นได้ (200) |
| K2b | คลิปที่สอง | อัปโหลดได้ **แต่ปุ่มเลือกวิดีโอยัง disabled หลังอัปโหลดสำเร็จจนกว่าจะรีโหลด** (`uploadState` ค้างที่ `done`) → บันทึกเป็น annotation `known-issue` |
| K3 | เปลี่ยนเกรดอ้างอิงของคลิป | PATCH 200, API แสดงเกรดใหม่ |
| K4 | ลบคลิปผ่านกล่องยืนยัน | DELETE 2xx, เหลือ 1 คลิป |
| K5 | รายการชุดแสดง "คลิป 1 คลิป"; Member เรียก API → 403; ชื่อว่าง → 400 | ตามที่ระบุ |
