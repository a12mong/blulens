# Gate: ตัวแก้ไขเกณฑ์ประเมิน (/committee/rubrics, 13d21d6)

ไฟล์: `apps/web/e2e/slice-rubrics.spec.ts` · ไม่ใช้ SQL · ทุกรอบสร้างเวอร์ชัน active ใหม่ใน `blulens_e2e` (ต่างกันแค่น้ำหนักข้อแรก) สเปกอื่นอ่าน key ของเกณฑ์จาก `/rubric` แบบไดนามิกจึงไม่กระทบ

| ขั้น | ตรวจ |
|---|---|
| R1 | รายการมี active 1 รายการ; "สร้างร่างจากเกณฑ์ที่ใช้อยู่" ได้ 201 และปุ่มหาย (มีร่างได้ 1 ฉบับ); สร้างซ้ำ → 409 `RUBRIC_DRAFT_EXISTS`; ร่างคัดลอกเกณฑ์ครบ |
| R2 | แก้ไข: key ผิด/น้ำหนัก 0 บันทึกไม่ได้และมีข้อความ; แก้น้ำหนัก+คำอธิบายระดับแล้วบันทึก → `rubric-saved`, API ตรง, active ไม่เปลี่ยน |
| R3 | ไม่เปิดเผยพารามิเตอร์การให้คะแนน: รูปทรง rubric มีแค่ id/status/createdAt/methodVersion/criteria, ไม่มีคำว่า outlier/margin/minReviewers/kappa |
| R4 | เปิดใช้ต้องมีเหตุผล ≥5 → active ใหม่ 1 รายการ, ของเดิม `retired`; ผู้ตรวจเห็นน้ำหนักใหม่จาก `GET /rubric` |
| R5 | เวอร์ชันที่ไม่ใช่ร่าง: หน้าแก้ไขเป็น read-only; PUT/DELETE/activate → 409 `RUBRIC_NOT_DRAFT` |
| R6 | ลบร่างผ่านกล่องยืนยัน → 204; Member/Reviewer เรียก `/rubrics` → 403 |

ยังไม่ครอบคลุม: เพิ่ม/ลบ/เรียงลำดับเกณฑ์ใน UI, จำกัด 12 เกณฑ์, เตือนก่อนออกจากหน้าที่ยังไม่บันทึก, ผลต่อ assessment ที่ส่งหลังเปิดใช้
